## Rule 1 — Relative reference

Everything is read relative to:

`+ ↔ (0) ↔ -`

- `(0)` = current reference / balance / pivot.
- `+` and `-` are opposed directions relative to that reference.
- Neither side is inherently good or bad.
- Do not interpret `+` or `-` until the reference is defined.

## Rule 2 — Field / Void

- FIELD = active interactions.
- VOID = unexpressed potential.

Field is what is actively happening or being expressed.
Void is what remains available but is not currently expressed.

They are paired roles around the same reference.
Void is not simply nothing.
