# Star Forge

## Short description
Mediator-led AI workbench for building and validating real projects.

## Store description
Star Forge is a Linux desktop workbench for structured AI-assisted building.

A persistent Mediator keeps the project grounded: it maintains the project plan,
current reference, layers, branches, journal, project map, validation state, and
the next bounded step. Field performs the build. Void independently checks the
result before anything advances.

Star Forge is designed for building real programs first, then extending the same
workflow into electronics: virtual breadboards, circuit simulation, PCB design,
bench-test plans, physical measurements, and simulation-versus-reality checks.

Core standards are always visible:
- reference before action
- real tests before promotion
- independent checking
- anti-drift scope
- targeted local fixes
- simplicity first
- ease of use first
- usefulness before complexity
- validation maturity tracked explicitly
