# Background-Calibrated Sizing Grid Rule

**Status: LOCKED**

Background first.

Placing the background PNG creates or adjusts the scene's sizing/perspective calibration. That calibration is saved with the scene.

The sizing grid is visible only while placing or sizing PNG characters and props. It hides again afterward.

The grid is an editor tool only and never appears in final export.

Depth-to-scale math is not implemented by this rule; this only locks when the grid is calibrated and when it is visible.
