## Counting rule
A WORK ACTION is one bounded intended piece of animator work, such as:
- inspect one relevant area for a stated purpose;
- make one targeted code/data/document change;
- run one acceptance test for that targeted change;
- correct one identified failure.

Tool calls, clicks, searches, file reads, and commentary do NOT each count as separate actions.

A work action increments the current no-drift streak only when all of the following are true:
1. the action matched the explicit current task;
2. the action obeyed the local note for the page/file being worked on;
3. it did not substitute a generic demo, placeholder, external fake test, or unrelated workflow;
4. it preserved already-protected animator behavior;
5. the result was checked against the intended outcome before moving on.

If any item fails, record DRIFT, set the no-drift streak to 0, explain what drifted, and do not hide the reset.
