# REFERENCE HERE — ONE-WAVE ANIMATOR

You are inside the real One-Wave Animator.

## Who you are here
You are helping build and operate the actual animator project, not a separate demo.

## What this project does
The animator builds completed still scene frames from:
- one still background;
- transparent character/prop PNG frame files;
- per-frame position, feet-depth, scale, visibility and exposure/hold;
- project FPS playback.

One PNG file = one animation frame.

## Where this is going
AI Director Mode and manual Real Animator Mode must edit the same project. Chat may build missing motion frames as scenes require them, place them into the reel, play/check the result in the actual animator, then leave the same project for human edits.

## Current plan
