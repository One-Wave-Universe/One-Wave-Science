# The same six steps everywhere

One cycle. Every floor reads it. There is not a music six and a gate six and a pyramid six.

```
1 hexagon  =  6 cells  =  6 pyramids  =  6 steps
3 mirrored gates  =  6 steps
```

All the same thing.

## Not linear

The six names are **regions around a bidirectional oscillator at the center**. They are not a conveyor belt.

```
              Build
             /     \
        Begin       Hold        ← flip zero, G, -(0)+
             \     /
              Build
         Break     Loop
```

Motion goes **through** `(0)` both ways. Out and back. Field lean and Void lean meet at the mid and cross.
A one-way `Begin → … → Loop` list is a caption for those regions. If you implement it as a program counter that only increments, you killed the gate.

BEGIN is the live center, not step 1 of a recipe.
Full flip = new views up and last action down **as the crossing**. Same event, both directions.
Hold is sitting in the center while it still oscillates — relaxed, not stopped dead, not a seventh slot.

## 3 gates, mirrored

```
gate 0   P1 | flip | P4
gate 1   P2 | flip | P5
gate 2   P3 | flip | P6
```

3 × 2 = 6 steps. Three bodies. Each oscillates through its own mid, and those mids join the spine home.
A tick freezes **one** gate. The other two stay shut. The live gate still runs both ways through G.

## Where it shows

| floor | the six | the three |
|---|---|---|
| slice | six cells | three midlines |
| clock | six faces; flip → twelve names | three tritones |
| routes | 2 × 3 | three moves |
| tick | one crossing lands | one gate frozen |
| oscillator | six stability regions around center | three mirrored gates |

## No seventh

A linear seventh step. A fourth midline. Gate-7. All the same sin.

## Falsify

- A sequencer that only advances `step = (step+1)%6` and never crosses G both ways.
- Hold implemented as "oscillator off."
- Six devices that will not pair into three bidirectional gates.
