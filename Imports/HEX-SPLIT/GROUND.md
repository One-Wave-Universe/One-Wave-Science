# Virtual ground is the ternary solution

```
-(0)+
```

That is the whole trick. Not three powered polarities. Two lives around a reference that is allowed to sit.

## Asymmetry moves. Balance holds.

```
A ≠ -A     write leaves the mid     movement
A = -A     write lands on the mid   hold
```

Opposed rings both loud is not hold. That is two movements fighting — quit, not sit.

## Every step has rails and a mid

Balanced and referenced at **every** step. Not one mid for the whole board and two rails for the universe.

```
        + rail     (one 1)
           |
step n —  mid G_n  — referenced here
           |
        - rail     (the other 1)
```

That is `1(0)1` in copper. The evaluator of that step only believes voltages against **its** `G_n`.

Then the mid goes home:

```
G_step → G_cluster → G_cube → controller
```

Down the middle. Each floor keeps its own outer rails. The rails are local clothes. The mids form the spine. VTC said this: local mirrored elements → triad reference → cluster reference → folded reference. No layer reads an absolute state without the local mid that makes the state mean something.

Do not feed three steps from one pair of rails and one far-away `G`. The far step then measures someone else's drop and calls it a write.
Do not share rails across floors without restating the mid. That smashes stack into slice.
A parent may *condition* a child. It does not steal the child's `G`.

Scale ladder is the same picture: `L > 1(0)1 < R` at every floor. Outer counts change. The unit pair does not divide.
