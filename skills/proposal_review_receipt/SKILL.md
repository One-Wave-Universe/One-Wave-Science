# Proposal Review Receipt Skill

## Purpose
Prevent unverified proposals from becoming project state.

## Input
A proposal packet containing:
- reference
- intention
- consequence
- constraints
- proposed change

## Review
Collect independent reviews.
Keep each review separate until comparison.

Compare:
- agreements
- disagreements
- assumptions
- unknowns
- tests needed

## Output
Create a receipt:

- proposal
- references used
- reviewers
- tests run
- failures
- results
- verification state

## Merge rule
A proposal remains a proposal until a receipt and verification exist.
