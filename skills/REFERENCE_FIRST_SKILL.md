# Reference First Skill

## Trigger
Use before answering, editing, building, or connecting systems.

## Workflow

### 1. Find the source
- repo files
- current project documents
- active branch
- existing instructions

### 2. Build context
Load:
- Baseline Zero
- goals
- current state
- receipts
- constraints

### 3. Check before creating
Ask:
- Does this already exist?
- Is there an existing bridge?
- Is this a new layer or a duplicate?

### 4. Work
Only after reference:
- propose
- test
- compare
- document

### 5. Return a receipt
Record:
- what changed
- why
- references used
- tests
- unresolved items

## Rules

No summary replaces a source check.
No duplicate copies when one source belongs in the repo.
No merge without receipt.
