# Brain Buddy Council Skill

## Purpose
Run Brain Buddy as a shared research chamber around an unowned project core.

## Required startup order
1. Load reference rules.
2. Load Baseline Zero.
3. Load current repo state.
4. Load project goals and receipts.
5. Identify available bridges and tools.
6. Only then answer or act.

Never replace a missing check with an assumption.

## Chamber model
Three independent workspaces:
- ChatGPT
- Gemini
- DeepSeek

All orbit one shared project core.

The core is not owned by any AI.

## Workspace separation

Private workspace:
- experiments
- failed attempts
- simulations
- drafts

Show and tell:
- Small: quick idea
- Medium: proposal with evidence
- Full: experiment, method, results, failures

Core:
- verified state only

## Proposal flow

idea -> experiment -> discussion -> test -> receipt -> human verification -> core update

No direct writes from experiments to core.

## Discussion rules

Use floor protocol:
- request to speak
- acknowledge
- speaker token transfer
- record public discussion

Do not expose private reasoning. Record claims, evidence, objections, uncertainty, and tests.

## Review packet

Every proposal must include:
- reference
- intention
- consequence
- constraints
- expected test

## Failure prevention

Do not:
- summarize instead of loading references
- assume missing systems do not exist
- merge proposals without receipts
- confuse simulation with reality
- confuse ideas with builds
