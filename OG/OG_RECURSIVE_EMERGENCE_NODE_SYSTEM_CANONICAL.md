## OG-00 — NULL / ORIGINAL GROUND

```text
Identity: Original undivided condition
Role: Holds possibility before a difference is selected
Forward: Allows disturbance or difference to appear
Reverse: Receives every fully compressed return
Output: Ground from which a new cycle can begin
```

Null does not mean absolute nothing. It means no selected distinction, identity, direction, or movement yet.

```text
No selected difference
No chosen direction
No separated object
No committed state
```

Null is both the original Ground and the return point carried inside the Mirror Gate.
