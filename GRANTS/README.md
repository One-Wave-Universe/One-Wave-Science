**Purpose:** convert the repository into a proposal-ready research program without overstating unverified claims.

## Grant-writing rule

Every proposal claim must be traceable to one of four classes:

- **Established external baseline**
- **Repository-validated engineering/simulation**
- **Preliminary result**
- **Unverified hypothesis / proposed test**

Do not collapse these categories.

## Core proposal framing

The strongest grant case is not "we have proved a new theory."

It is:

> We have built an unusually broad, instrumented research environment for testing a set of explicit, falsifiable hypotheses linking continuous-medium physics, state-machine architecture, associative memory, and low-voltage hardware. Funding would convert the current exploratory repository into a disciplined experimental program with preregistered controls, reproducible simulation, calibrated acquisition hardware, and go/no-go milestones.

That framing is compatible with the repository's current evidence state and gives reviewers something concrete to fund.
