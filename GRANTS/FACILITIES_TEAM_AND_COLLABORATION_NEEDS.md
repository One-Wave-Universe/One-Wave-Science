# Facilities, Team, and Collaboration Needs

## Existing assets represented in the repository

The project already includes:
- substantial software and documentation infrastructure;
- Virtual Breadboard and circuit-simulation work;
- Jetson-oriented local compute plans;
- CELL_V1 hardware architecture;
- V1 verification matrix;
- proposed Wave Reader acquisition path;
- open collaboration and construction rules.

## Team capabilities still needed for a strong grant

Priority collaborators:

1. **Experimental electronics / instrumentation**
   - analog front ends;
   - ADC qualification;
   - low-noise measurements;
   - PCB and bench validation.

2. **Numerical methods / computational physics**
   - PDE/ODE formulation;
   - stability/convergence analysis;
   - control comparisons;
   - dimensional analysis.

3. **Domain expert for any cross-domain claim**
   - biochemistry/biophysics for ATP work;
   - neuroscience/physiology for affective-state work;
   - astrophysics/plasma physics for quasar work.

4. **Research software / reproducibility**
   - packaging;
   - CI;
   - datasets;
   - environment locking;
   - release engineering.

5. **Independent reviewer/advisor**
   - challenge assumptions;
   - review preregistration;
   - audit null/negative results.

## Facility needs

Minimum serious bench:
- calibrated oscilloscope;
- waveform generator;
- bench supply;
- precision multimeter;
- safe low-voltage prototyping area;
- ESD/basic electronics tooling;
- computer/Jetson acquisition workstation;
- reliable versioned storage and backup.

Nice-to-have later:
- differential/active probes;
- LCR meter;
- environmental control/temperature logging;
- PCB rework station;
- magnetics characterization;
- access to an institutional electronics lab.

## Collaboration package

Before outreach, prepare:
- one-page project summary;
- one-page experimental spine;
- current evidence table;
- exact requested collaborator role;
- bounded first task;
- statement that hypotheses are unverified and intended for falsification.
