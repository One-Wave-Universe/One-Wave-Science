# Project Summary

## Working title

**One-Wave Experimental Platform: A Reproducible Simulation, Measurement, and Hardware Program for Testing Continuous-Medium and State-Recurrence Hypotheses**

## Overview

This project proposes a staged experimental program to test a family of unverified but explicit hypotheses currently organized in the One-Wave Science repository.

The repository combines:

- a validated Virtual Breadboard / circuit-simulation track;
- explicit physics and state-machine hypothesis nodes;
- a V1 verification matrix;
- low-voltage CELL_V1 hardware concepts;
- associative-memory software prototypes;
- a proposed Wave Reader acquisition chain;
- Jetson-based local compute and automation;
- reproducibility and evidence-status rules.

The central research question is not whether all One-Wave claims are correct. It is whether any subset of the proposed continuous-medium, recurrence, memory, and hardware relationships survive controlled comparison against established baselines.

## Intellectual merit / technical significance

The project is designed around falsifiability and instrumented comparison. Its novelty lies in combining:

1. hypothesis-level continuous-medium models;
2. explicit control-vs-hypothesis simulation;
3. physical low-voltage state-machine prototypes;
4. direct acquisition and reproducibility receipts;
5. a shared evidence graph that preserves both successful and failed results.

A successful project would produce either:
- support for one or more narrowly defined mechanisms that justify deeper study; or
- high-quality negative results that eliminate unsupported formulations and improve the architecture.

Both outcomes are scientifically useful.

## Broader impacts / practical value

Independent of the fate of the physics hypotheses, the project is expected to produce:

- open simulation and measurement tooling;
- a reusable virtual breadboard and experimental workflow;
- low-cost instrumentation documentation;
- reproducible data and test receipts;
- educational visualizations of state machines, control systems, and experimental reasoning;
- a documented workflow for AI-assisted hypothesis testing that separates speculation from evidence.

## Current status

The repository contains substantial architecture, simulation, and test infrastructure, but the new V1 hypothesis layer remains explicitly **UNVERIFIED**.

The immediate funding need is to convert the existing exploratory work into a reproducible experimental program with calibrated hardware, stable software entry points, bounded test plans, and externally reviewable results.
