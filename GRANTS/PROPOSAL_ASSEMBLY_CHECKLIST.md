# Proposal Assembly Checklist

## Scientific narrative
- [ ] one-sentence problem
- [ ] one-sentence opportunity
- [ ] central hypothesis stated as unverified
- [ ] 2–5 specific aims
- [ ] clear comparator/control for each aim
- [ ] go/no-go criteria
- [ ] alternative strategies
- [ ] scope narrow enough for requested budget and period

## Preliminary evidence
- [ ] every preliminary claim has a repo path
- [ ] figure source data preserved
- [ ] simulation and measurement clearly distinguished
- [ ] negative results included where relevant
- [ ] no speculative claim labeled validated

## Methods
- [ ] variables and units
- [ ] equipment
- [ ] software versions
- [ ] calibration method
- [ ] replication count
- [ ] analysis plan
- [ ] acceptance/failure criteria

## Team
- [ ] project lead identified
- [ ] electronics/instrumentation expertise covered
- [ ] computational expertise covered
- [ ] domain expertise covered where needed
- [ ] letters/collaboration commitments requested
- [ ] facilities access documented

## Budget
- [ ] quotes or realistic estimates
- [ ] personnel effort justified
- [ ] equipment tied to milestone
- [ ] no premature specialized purchase
- [ ] external calibration/review budgeted if needed

## Reproducibility
- [ ] data plan
- [ ] code release plan
- [ ] version tags
- [ ] environment lock
- [ ] raw-data retention
- [ ] reproducible command/workflow

## Reviewer usability
- [ ] proposal-facing README
- [ ] one-page evidence table
- [ ] architecture figure
- [ ] milestone timeline
- [ ] risk table
- [ ] link to technical repository
- [ ] no reviewer needs to understand the entire repo to evaluate the funded experiment
