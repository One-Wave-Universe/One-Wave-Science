# Node E-531: Dual-Harmonic Propagation Operator

## Purpose

Lock the separation between **propagation structure** and **bound-state structure**.

Octave / dual-harmonic recurrence governs wave propagation.  
It does **not** organize the mass spectrum.

## Definition

The dual-harmonic operator acts on a local frequency (or harmonic index) label \(H\):

\[
\boxed{
\bigl((H+1)\cdot 2+1\bigr) - \bigl((H+1)\cdot 2-1\bigr) = 2
}
\]

The identity returns exactly \(\Delta H = 2\) on any field that carries a harmonic index.  
It is geometry, not dynamics: it constrains how frequency labels step under reflection / leaning / transport.

## Domain of validity

| Domain | Dual-harmonic applies? |
|--------|------------------------|
| Frequency tracks, chirps, GW evolution | Yes |
| Redshift / transport along a path | Yes |
| Lattice free-field propagation | Yes |
| Bound-state mass ratios | **No** |
| Particle spectrum organization | **No** |

Mass is a bound-lattice phenomenon (see E-532). Treating mass ratios as continued octave steps is a category error. A null test on the integer/half-integer mass ladder returned no significant clustering; that result is recorded here as a permanent boundary, not a temporary failure.

## Working separation

| Domain | Governing structure |
|--------|---------------------|
| Propagation, frequency evolution, redshift, GW tracks | Octave / dual-harmonic recurrence (this node) |
| Bound excitations, stability, residual channels | Bound-lattice criterion + finite wakes (E-532) |

The two interact (a bound core can source a wake that then propagates under the dual-harmonic rule), but they are not the same scaling series.

## Absolute scale

The operator fixes relative steps. The absolute frequency that would link the gravitational-wave band to residual mass-squared differences remains free. Until that scale is pinned, residual-channel targets stay targets, not derivations.

## Mathematics (site-level)

On a lattice, the discrete gradient or local harmonic index inherits the identity site-by-site. Any update that preserves the free-field structure automatically preserves \(\Delta H = 2\) on the propagation sector. Bound cores may be projected out of the free sector before the operator is applied.

## Failure / falsification

- If a clean mass-ratio series is later shown to follow the same dual-harmonic steps under controlled conditions, this node’s domain boundary must be revised.
- If lattice free-field runs lose \(\Delta H = 2\) under the same update laws that preserve energy and bound flags, the operator form itself is wrong.
