# E-545 — Rotation Initiation: Point, Path, Field

Rotation starts when a differential reaches a resistant boundary and produces unequal response around a center.

```text
Differential -> Boundary -> Asymmetry -> Rotation
```

- Point: local torque/spin around the immediate center.
- Path: the moving point is continuously redirected by external relations.
- Field: the path organizes the surrounding medium, pressure, return flow, and boundaries.

Nested rule: `Field_n -> Point_(n+1)`.
