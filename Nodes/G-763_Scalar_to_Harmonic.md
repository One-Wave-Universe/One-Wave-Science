# G-763 — The six words

```text
scalar      differential     vector
tensor      stratum          harmonic
```

Top row Field copy. Bottom row Void / next-copy. Same three: intersect, oppose, invert — twice.

| Word | What it is here |
|---|---|
| scalar | one number on Ground. E. HOLD. `(0)` |
| differential | two rails. d. YES/NO. Field minus Void |
| vector | the move. DOWN/UP. Path. ternary along a directed edge |
| tensor | carry. `M_ij`, `W_ij`. quadratic views/actions |
| stratum | which nest layer. cell chip cube Rubik |
| harmonic | the closed loop / next-scale DC. not a seventh gate |

Intersect sits on scalar\leftrightarrow tensor (same shape, cut).
Oppose sits on differential\leftrightarrow stratum (pair vs layer pair).
Invert sits on vector\leftrightarrow harmonic (move flips into the standing cycle).

Do not add a seventh word. 2 choices \times 3 moves = these six names, not six extra axes.
