## 9. Executable commitment model

Not a universal physical law. Executable control model.

Phase lock:

$$L(\Delta\phi)=\frac{1+\cos(\Delta\phi)}{2},\qquad 0\le L\le 1$$

Latent update:

$$q_{n+1}=\mathrm{clip}\bigl(r\,q_n + g\,b\,m\,d\,L,\;-q_{\max},\;+q_{\max}\bigr)$$

| Symbol | Meaning | Constraint |
|---|---|---|
| r | retention fraction | 0 ≤ r ≤ 1; reference 0.92 |
| g | new-drive gain | g ≥ 0; reference 0.24 |
| q_max | clamp | reference 1 |
| d | bounded differential magnitude | 0 ≤ d ≤ 1 |
| b | Field polarity | NEGATIVE = −1, POSITIVE = +1 |
| m | signed movement projection | −1 / 0 / +1 |

`b` is polarity, not ACCEPT/REJECT.
`m` does not rename MODULATE / HOLD / RESET.

### m projection

| Primitive | Condition | m |
|---|---|---|
| HOLD | \|d(n)−d(n−1)\| ≤ movement_hold_width | 0 |
| RESET | d(n) > epsilon and d decreasing toward reference | −1 |
| MODULATE | d(n)−d(n−1) > movement_hold_width | +1 |
| MODULATE | d(n−1)−d(n) > movement_hold_width | −1 |

RESET cannot emit +1 while correctly resetting. HOLD requires m = 0.

### q → five-state readout

Readouts: FULL DISAGREE −3, PARTIAL DISAGREE −2, UNITY / UNCOMMITTED 0, PARTIAL AGREE +2, FULL AGREE +3.
±1 is not used. Do not fill.

Hysteresis on \|q\|:

```text
partial_exit  = 0.28
partial_enter = 0.40
full_exit     = 0.68
full_enter    = 0.82
```

Rules:

- From 0: \|q\| < 0.40 stays 0; \|q\| ≥ 0.40 enters same-sign ±2.
- From ±2: \|q\| < 0.28 → 0; 0.28 ≤ \|q\| < 0.82 stay partial; \|q\| ≥ 0.82 → same-sign ±3.
- From ±3: \|q\| < 0.68 leaves full, then partial/neutral rules apply.
- If q changes sign, readout returns 0 first. No direct committed sign flip.
