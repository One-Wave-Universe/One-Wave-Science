# Node E-542: Local Peak-Trough Back-Mapping — No Spooky Action

Dependencies:
Upstream: E-541, E-532, F-605 Interference, F-606 Reflection, B-206a Shared Boundary, OG-09 Reference
Downstream: Book 1 Chapter 9, entanglement/public explanation, Truth Computer tests

Definition:
Strong correlations do not require objects to send instant secret messages across distance. Correlated measurements can arise because both measurement paths are local readouts of one previously coupled wave structure whose peak, trough, phase, polarity, and boundary relationships were established together.

Shared Origin:
When one field event is split, reflected, opposed, or measured along paired routes, the routes retain complementary structure. The correlation is carried in the full wave organization and shared boundary history.

Local Measurement:
Each detector interacts locally with the wave condition reaching it. The detector selects a basis, focal condition, or threshold and returns a bounded event.

Back-Mapping:
The two records are later mapped back to the shared wave relation. Peaks, troughs, phase, orientation, and complementary constraints reconstruct the correlation. The match does not require a signal to travel between the detectors at measurement time.

No Spooky Action:
One-Wave rejects “spooky action” as an explanation. The model requires:
- one continuous field;
- shared preparation or coupling;
- complementary wave structure;
- local detector interaction;
- later comparison of records.

No Hidden Pellet Pair:
The alternative is not two tiny particles carrying prewritten answer cards. The relevant state is distributed wave relation plus the detector interaction that turns it into discrete records.

Test Requirement:
A One-Wave simulation must track the complete pre-measurement field, both local detector couplings, and the post-measurement comparison. Plotting only two final bits is insufficient because it deletes the wave structure that is supposed to explain the correlation.
