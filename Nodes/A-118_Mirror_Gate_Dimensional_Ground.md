# Node A-118: Mirror Gate Dimensional Ground

Dependencies:
Upstream: OG-00 Null / Original Ground, A-101 Ground Zero, B-205 Mirror, C-301 Mirror Gate
Downstream: E-537, E-538, E-539, C-323, E-540, E-541, E-542, E-543 and every One-Wave book chapter

Definition:
Ground Zero is the Mirror Gate between two native spatial conditions of the one field:

- compressed negative 2D space;
- expressed positive 3D space.

The Mirror Gate is not a flat object placed inside an already-existing 3D container. It is the shared dimensional boundary through which compressed relation is expressed as volume and expressed volume is recompressed as relation.

Canonical relation:

`2D negative/compressed <-> Mirror Gate 0 <-> 3D positive/expressed`

The two sides are reciprocal states of one field, not separate universes or substances. Every complete One-Wave definition must identify the 2D condition, the Gate conversion, the 3D condition, and the return path.

2D Side:
The 2D side carries compressed relation, adjacency, pattern, phase, memory, possibility, internal mapping, dream construction, awareness, and mirrored magnetic organization. Depth is not physically expressed as volume. Metric travel is therefore not the governing relation.

Mirror Gate:
The Gate performs inversion, comparison, focal selection, compression, expression, mapping, and return. It preserves identity by mapping peaks, troughs, phase, pressure, direction, and boundary relationships across the dimensional change.

3D Side:
The 3D side carries expressed volume, measurable separation, physical resistance, displacement, motion, shells, bodies, electrical flow, and externally observable interaction.

Mandatory Chapter Rule:
No chapter may define a subject only in 3D. Every chapter must state:
1. compressed 2D definition;
2. Mirror Gate operation;
3. expressed 3D definition;
4. bidirectional cycle;
5. measurement/display consequence.

Failure Condition:
Any summary that presents the Mirror Gate as merely a surface inside 3D, omits negative 2D space, or treats 2D as a visualization shortcut has removed Ground Zero and is noncanonical.
