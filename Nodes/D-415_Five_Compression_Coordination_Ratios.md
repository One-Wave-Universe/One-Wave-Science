# D-415 — Five Compression Coordination Ratios

## Purpose

Formalize the five-count compression/coordination ladder separately from the five computational states and the six process steps.

## Ratio Ladder

Current normalized form:

`1:1 → 1:3 → 1:6 → 1:12 → 1:24`

Represent each ratio as

`r_k = 1 / N_k`

with

`N = {1, 3, 6, 12, 24}`.

The associated coordination counts are therefore:

`C = {1, 3, 6, 12, 24}`.

## Interpretation Rule

The ratio by itself is incomplete. Every use must declare what is being compared, for example:

`r = local_units : parent_unit`

or

`r = active_routes : reference_route`

or another explicitly defined domain.

A ratio must not silently change orientation. If a source writes `12:1` or `24:1` instead of `1:12` or `1:24`, the source must state whether that is an intentional inverse relation:

`r_inverse = 1 / r`.

## Dimensional Associations Under Test

The current structural associations to preserve for testing are:

- `1:3` — ternary/three-way relation,
- `1:6` — sixfold 2D coordination candidate,
- `1:12` — twelvefold 3D close-packed coordination candidate,
- `1:24` — twenty-four-step/route 4D recurrence coordination candidate.

`1:1` is the uncompressed/local reference case.

These associations are architectural hypotheses until a specific physical derivation or simulation establishes the mapping.
