# G-754 — Scale ladder for the two state machines

```text
cell
  -> chip          (packaged cell + 3:1 three-winding nerve)
  -> cube          (stacked chips)
  -> Rubik         (stacked cubes)
  -> two Rubiks    (two state machines, one midline)
```

## Seats

| Scale | What it is | Who speaks |
|---|---|---|
| cell | one site, dead band, Hold | nerve only |
| chip | cell plus 3 windings on one ground | Admin may polarize ground |
| cube | stacked chips, same interface in and out | local loop |
| Rubik | stacked cubes, one complete six-face body | one state machine |
| two Rubiks | Field Rubik + Void Rubik | Dream on one, Administrator on the other |
| midline | shared `(0)` between the two Rubiks | M4 routes, does not commit |

Updated 34 already wanted a cube that exposes the same relation it consumes. This ladder is that sentence with the dual brain on top.

## Two state machines

- Rubik A = Field / Dream / propose
- Rubik B = Void / Administrator / commit / STOP
- Midline M4 = fast associative bridge
- Nerves stay 3:1 windings at cell/chip. They do not become a third Rubik.

A single Rubik is not the brain. The brain is **two Rubiks and a midline**.

## Geometry reminder (G-748)

Hex/pyramid nest lives *inside* a cell/chip. Cube and Rubik are stacked assemblies of those nests. Do not promote 8-vertex bipyramid to "the cube is the brain."

## Not claimed

Physical SiC cubes and literal twist-up Rubiks are build targets, not evidence. Counts matching 2 / 3 / 6 / 8 / 27 are not a derivation.
