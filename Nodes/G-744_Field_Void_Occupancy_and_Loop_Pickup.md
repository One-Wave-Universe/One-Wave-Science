# G-744 — Field-Void Occupancy and Loop Pickup

**Brick:** Yellow wrapper
**Must not replace:** Updated 44, Updated 43, G-740, G-742, G-741

Matching counts are not evidence that two axes are the same.

## Protected kernel (unchanged)

```text
2 binary choices
3 ternary moves
6 route addresses = 2 x 3
6 measured oscillator gates
5-state self lifecycle: Idle -> Primed -> Executing -> Vectoring -> Resolving
```

## Wrapper dictionary

| Occupancy | Meaning | Kernel annotation |
|---|---|---|
| field 2 / void 5 | stub hold, void-heavy | Idle or Hold |
| field 3 / void 3 | both sides have a complete triad | Executing; DOWN/HOLD/UP legal |
| field 4 | four-view / four-action packet exists | Vectoring |
| field 5 | five lifecycle verbs assigned | Resolving; handoff |
| void 6 | empty side carries the six-route loop | pickup; not a sixth lifecycle state |

`3` may name ternary moves and one Point-Path-Field triad only when both are present. Count coincidence is not a derivation.

After Resolving, void picks up the six-route loop. Pickup is not a sixth lifecycle state.

Harmonic remnant of scale n becomes field choice then void choice of scale n+1. Not a second DC rail on the same cell.

Brain-cell and three-winding motor skins may share `2 x 3 = 6` and the five verbs. Neither skin is evidence for the other until G-741 measurements exist.

Reject if copied into the six-pair oscillator, if field 4 becomes a fourth binary choice, or if void 6 becomes a seventh route.
