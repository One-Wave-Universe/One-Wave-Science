# D-418 — Finite-Range Gravity Relay and Nested Parent Epicenters

## Purpose

Test the One-Wave hypothesis that a local gravitational/displacement influence has a finite direct active domain and is then carried onward through nested parent fields rather than remaining an unchanged direct source acting to infinity.

This is **not** a claim that Newtonian or relativistic gravity has already been falsified.

## Core hierarchy

```text
local body
-> stellar-system parent
-> galactic parent
-> cluster parent
-> supercluster / Great-Attractor-scale parent
```

Each child:
- inherits the resolved parent reference;
- modifies the parent state;
- carries its own Point / Path / Field structure;
- contributes to the next parent update.

The resolved state of one scale becomes part of the reference state of the next.

## Current-state relay vs stored wake memory

Relay does **not** mean that an old source leaves a permanent detached force behind.

The allowed hypothesis is:

```text
current child state
+ current parent state
+ current overlap / geometry
-> current parent update
-> next-scale reference
```

A vanished interaction is not preserved merely because it once existed.

## Child weight

"Child weight" is not assumed to equal mass alone.

A valid common law may depend on independently measurable inputs such as:
- mass/energy;
- density structure;
- point rotation;
- orbital/path rotation;
- magnetic state;
- compression/bound state;
- distance and orientation within the parent field.

No private weight formula may be tuned separately for each galaxy, star, or planet.

## Great Attractor / cluster / galaxy test

The hierarchy must be evaluated across:
- local stellar systems;
- galaxies;
- galaxy clusters;
- supercluster-scale flow / Great-Attractor-scale environments.

The aim is to test whether one recursive parent/child law can reproduce local orbital behavior while also describing larger-scale collective motion.

## Key discriminator

If ordinary direct long-range gravity and the relay hierarchy make identical predictions for every observable, D-418 is only a reformulation.

A distinct theory requires a predeclared observable near a parent/child transition where the relay model predicts a quantitative departure.

## Failure conditions

D-418 fails if:
- the relay radius is chosen independently for every object;
- child weights are retuned per system;
- the parent state is only a verbal label with no update equation;
- "relay" reduces exactly to adding the original source field unchanged at all distances;
- the model cannot recover known local inverse-square behavior in its valid local regime.
