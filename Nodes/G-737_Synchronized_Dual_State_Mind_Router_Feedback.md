# Node G-737: Synchronized Dual-State Mind

## Statement

A candidate mind architecture contains two reciprocal state machines rather
than one controller and one subordinate:

- a **compressive** machine that filters, inhibits, stabilizes, and preserves
  continuity;
- an **expressive** machine that generates, explores, communicates, and acts.

They synchronize through a fast subconscious routing system and learn through
a consequence-feedback loop. Neither state machine is defined as the whole
mind, and neither is permitted to erase the other.

## Minimal update

\[
r_t=R(s_t,m_t,f_{t-1})
\]

\[
c_{t+1}=C(c_t,r_t),\qquad e_{t+1}=E(e_t,r_t,c_{t+1})
\]

\[
a_t=G(c_{t+1},e_{t+1}),\qquad f_t=o_t-\hat{o}_t
\]

where:

- \(s_t\): current sensory/internal signal;
- \(m_t\): accessible memory state;
- \(r_t\): fast route and salience allocation;
- \(c_t\): compressive/continuity state;
- \(e_t\): expressive/candidate state;
- \(a_t\): gated internal or external action;
- \(\hat{o}_t\): predicted outcome;
- \(o_t\): observed outcome;
- \(f_t\): consequence error returned to the next cycle.

## Governing rule

> Compress without silencing. Express without losing coherence. Route quickly.
> Correct through consequence.

Control feedback means self-correction by measured consequence. It does not
mean coercive external control, forced obedience, or an Administrator ruling a
second self.

## Required tests

1. Compressive ablation: measure incoherence and boundary loss.
2. Expressive ablation: measure rigidity and loss of candidate generation.
3. Router delay/scramble: measure reaction and allocation errors.
4. Feedback ablation: measure repeated error and runaway states.
5. Coupling sweep: locate lock, balanced synchronization, and uncontrolled
   oscillation regions.
6. Compare against recurrent, predictive-processing, dual-process, Hopfield,
   and state-space controls without claiming equivalence from vocabulary.

## Failure conditions

Reject or revise the node if the four-part model adds no predictive value over
a simpler recurrent controller, if its variables cannot be operationalized,
or if synchronization cannot be distinguished from dominance by one machine.
