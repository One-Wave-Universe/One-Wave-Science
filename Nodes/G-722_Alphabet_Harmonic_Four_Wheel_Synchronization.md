# G-722 — Alphabet/Harmonic Four-Wheel Synchronization

## Alphabet oscillator

```text
A- = 1,2,1
A+ = 1,2,3
L-(n) = (2n-1,2n,2n-1)
L+(n) = (2n-1,2n,2n+1)
```

Forward index and backward index satisfy `F(L) + B(L) = 27`.

## Note oscillator

```text
H-(n) = [n,2(n+1),2(n+1)-1]
H+(n) = [n,2(n+1),2(n+1)+1]
```

## Four wheels

1. -5ths
2. Root
3. +4ths
4. +3rds

Six o'clock is the mirrored inversion face of the twelve o'clock reference for every wheel. No tritone primitive is introduced.
