# D-414 — Four Dimensional Views

## Purpose

Define the four Views as dimensional readouts of one shared state rather than four unrelated forces or actions.

## Four Views

1. **1D View** — polarity/axis relation along one degree of freedom.
2. **2D View** — path/plane relation among coupled directions.
3. **3D View** — volumetric/rotational field relation.
4. **4D View** — recurrence/state-through-change relation across successive resolved states.

These are Views: they describe how a shared state is read. They are not the four Actions.

## Coordinate Skeleton

A minimal nested representation is:

`X_1 = (x)`

`X_2 = (x,y)`

`X_3 = (x,y,z)`

`X_4 = (x,y,z,ρ)`

where `ρ` is a recurrence/state coordinate, not automatically ordinary clock time.

Projection from a higher view to a lower view must be declared explicitly:

`P_(m←n): X_n → X_m,   m < n`.

No lower-dimensional drawing may be treated as the full higher-dimensional object without a declared projection.

## Cyclic/Seasonal Analogy

The current mnemonic phase cycle is:

`Spring/Birth → Summer/Life → Fall/Decline → Winter/Death → next Spring`

This is a phase analogy for a repeating tilted/rotating cycle, not an assertion that biological seasons define dimensional mathematics.
