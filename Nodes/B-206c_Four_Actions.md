# Node B-206c: Four Actions — Inward, Outward, Across, Over

## Definition

The Four Actions describe what a relational state can do after it has been read through the Four Views (`B-206b`). They were previously mislabeled as Views.

1. **Inward** — move/compress the active relation toward its local reference or center.
2. **Outward** — express/extend the active relation away from its local reference or center.
3. **Across** — establish/carry a relation across the opposed sides through the shared reference/boundary.
4. **Over** — cross the Mirror Gate, phase-shift, and re-emerge in the next orientation, path, cell, or recursive scale.

## Mirror-Gate Distinction

`Across` and `Over` are not synonyms.

```text
Across = establish/carry the relation through the shared `(0)` boundary.
Over   = complete the crossover/phase shift and emerge into the next orientation.
```

## Relationship to the Four Views

The Actions transform a state whose Views are:

```text
Direction
Phase
Strength
Reference
```

An Action can alter several Views at once. For example, `Over` may change phase and direction while establishing a new local reference.

## Recursive Use

The same action vocabulary can operate at multiple scales:

```text
local differential
 -> neighbor/path relation
 -> lattice field relation
 -> complete system relation
```

The names are scale-stable; their physical implementation is not assumed to be identical at every scale.

## Invariant-Engine Boundary

The Four Actions are a representation/operation layer above the six-pair oscillator. They must not change the invariant pair order:

```text
F1/V6 - V5/F2 - F3/V4 - V3/F4 - F5/V2 - V1/F6
```

## Operational Chain

```text
read Views
 -> Inward / Outward / Across / Over
 -> consequence
 -> updated reference/state
```
