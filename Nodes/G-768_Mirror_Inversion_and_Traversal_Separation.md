# Node G-768: Mirror Inversion and Traversal Separation

## Purpose
Keep three independent operations distinct.

1. **Mirror polarity** changes sign:
   [
   Xmapsto-X.
   ]

2. **Domain inversion** changes a domain's rank convention. Alphabet example:
   [
   N_{inv}=27-N.
   ]

3. **Opposing traversal** reverses route order without silently changing sign or rank convention.

These operations may compose but are never synonyms.

## Zero
The shared zero/mirror reference is not a letter, note, TOP, wrapper, or branch token unless a domain explicitly defines such a label.
