# Claude Animation Federation

A PNG still-frame animation and video production system, built branch-by-branch under a fixed constitution.

This is a separate implementation from `../One_Wave_Animator/`. It follows the same production principles (background as world, PNG characters placed in scene coordinates, ground/foot-based perspective, explicit frames) but is not a fork of that codebase and does not have permission to redesign those principles.

**Read `CONSTITUTION.md` in full before writing or reviewing any code here.** It is the standing law for this project: no branch order, and no "cleaner" alternative design, overrides it.

## Status

No branch order has been issued yet. Per the constitution's Build Discipline, work proceeds one branch at a time, each merged only after its acceptance test passes and the rendered output has been visually inspected. The constitution's own "First Development Target" section names the first primitive to prove (PNG background + character PNG + ground/foot position + perspective scale + explicit frames), but implementation does not start until that (or another) branch is explicitly ordered.
