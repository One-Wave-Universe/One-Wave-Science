# M4 Active World and Memory Router

M4 is not merely a message courier between Field and Void.

Current working role:

1. Receive the current cue / local state.
2. Route into memory using the cue, current reference, scale, phase, and active context.
3. Reconstruct the relevant active world from available memory.
4. Maintain that active world as the shared internal scene/context.
5. Present the active world across the Field/Void mirror.
6. Field asks/explores against that world.
7. Void answers/checks/compresses against that world.
8. Route the result back through the active world.
9. Update the working memory/reference and emit a receipt.

Working decomposition:

- Field / Dream: asks, explores, expands, generates possibilities.
- Void / Administrator / Checker: answers, validates, compresses, preserves continuity, confirms/defers/denies.
- M4 / Brainstem / Subconscious fast brain: memory router, associative recall, active-world constructor, context maintainer, state/scale/phase router, and bidirectional relay between Field and Void.

Important distinction:

- Field can generate candidate content for a dream or imagined continuation.
- M4 assembles the remembered/reconstructed context that makes the candidate meaningful as an internal world.
- Void evaluates that shared world and the Field question against current constraints/reference.

Memory path:

cue -> constellation neighborhood -> rabbit-hop route -> associative completion -> probabilistic fill when needed -> M4 active-world assembly -> Field/Void exchange -> consequence/context check -> working-state update -> receipt

This is a working architecture rule, not a claim about biological consciousness or a verified physical mechanism.
