# Reference at every step is the free update

You do not ship a new world each tick. You touch G again.

Local outer rails + local mid, every station, every window. That restatement *is* the update. Cost is the lean, if any. STAY + same G = free.

```
step n     measure vs local G     leftover B already sits here
step n+1   reference again        that is the update
           lean only if Field lists and Void allows
```

No global clock flood. No rebuild from zero. No PWM to remind the mid who it is.
Reinjection is this: next step inherits G and leftover B. Power stays at the floor until a lean spends.

If a station floats off its local mid, the next “update” is expensive — you pay to drag it home. Balanced and referenced at every step is the cheap path because home is already under the foot.
