# Council Chamber / Brain Buddy Workbench

A research room. Not three chatbots. Not the cell.
Center is unowned. Memory is a path back to source, not authority.

## Project Core (middle)

```
Baseline Zero
  Goals / Current State / References / Decisions / Receipts
  CANON   source documents     OWATCH fail-closed
  LOGIC   derived + tests      owatch-logic-kernel
  BENCH   sims / experiments   labeled simulation
  BUILD   physical             idea ≠ build ≠ verified
```

Change path:
idea → experiment → discussion → test → receipt → human verify → core update

No good-idea shortcut. Simulation ≠ reality. Idea ≠ build.

## Rooms

Around the core: Gemini, DeepSeek, ChatGPT (or appointed coder seat).
Grok may hold the coder seat on the stage or sit as a fourth room.
Each room has:
- private notebook / sandbox (fail safely, not shared by default)
- show-and-tell: Small / Medium / Full
  Small = noticed connection
  Medium = problem, approach, evidence, suggested test
  Full = experiment, code, results, failures, next

Show-and-tell is a presentation + receipt, not a merge.

## Council floor

lightbulb = request    green = speaker    ack = pass the floor
Visible: claims, questions, disagreements, evidence, tests.
Not visible: private scratch.
Packet still required: reference, intention, consequence, actor.
Missing → HOLD.

## Baseline Zero loop

discussion → reference check → compare core → strip drift → continue
Route hysteresis may help find the path back. It may not move the core.

## Benches hanging off the core

Science: claim / evidence / unknowns / next experiment
Physics engine: models and viz; labeled twin
Build: hardware; measurement is the only promotion
Shared coding: one SECTION, isolated tests (SHARED_CODING_BENCH.md)

## Receipt

What changed, why, reference, who proposed, test, fail, pass, who verified.
Without a receipt the conversation did not happen for the core.

## Never-finished rule

No finished flag. Status = sections passing / open / no-go hit.
Best-it-could-be = every open section receipted and no no-go waived.
