# Speculative Builds

This folder contains proposed engineering/control architectures moved out of the Science side of the repository.

## Boundary

Belongs here:
- CELL_V1 physical build packets and unbench-tested hardware proposals;
- Android brain/body implementation architecture;
- Hopfield/Boltzmann procedural-memory and reconstruction machinery;
- rabbit-hop routing/coordinate grammars used as build/control architecture;
- motor-memory, heterogeneous runtime, worker/agent, and controller proposals;
- speculative Virtual Breadboard build instructions and hardware packets.

Stays in Science:
- physical hypotheses and measurement claims;
- experimentally grounded reference data;
- canonical physics nodes that are not implementation/control architecture;
- runnable/validated simulator infrastructure and ordinary regression tests.

A working software implementation is evidence for that implementation, not proof of the physical science claim it may be used to explore.
