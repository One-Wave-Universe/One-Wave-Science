# POSTER — CELL + 3-WINDING ACTUATOR

```
+12 ─ highA ─ PA ─ winding A ┬
+12 ─ highB ─ PB ─ winding B ┤ STAR = G = blue = I_0
+12 ─ highC ─ PC ─ winding C ┴
           lows to −12

+1 = high ON   STAY = both OFF   −1 = low ON
Live one winding. Walk A-B-C rotates B. All STAY = hold.
First load: 3×1k to star. Motor stall must fit FETs + current knob.
```
