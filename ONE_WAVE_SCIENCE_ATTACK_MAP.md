# One-Wave Science Attack Map

Status: working research map. This file does not declare the theory complete or proven. Its job is to show what the One-Wave science currently claims, what evidence or mathematics exists, what is missing, and what to attack next.

## Core research rule

For every scientific claim, keep four things separate:

1. stated mechanism;
2. current derivation/model;
3. observations or experiments it must reproduce;
4. unresolved gap.

A claim advances only when the gap gets smaller.

## A. Primitive ontology

Current structural idea:

- one underlying wave/continuum rather than independent fundamental force/particle stories;
- local state is defined relationally to a reference;
- change is differential relative to that reference;
- opposed Field/Void organization around a shared center is recurrent;
- oscillation, asymmetry, phase, return, and retained history are central.

Attack next:

- define the minimum mathematical state variables;
- identify which are scalar, vector, phase, topology, or boundary variables;
- state conservation/continuity laws explicitly;
- identify what ordinary physics limit must be recovered when extra One-Wave terms go to zero.

## B. Ground / reference / center

Current structure:

- a shared reference or Ground is not an extra binary choice;
- local behavior is measured against a current reference;
- Hold is active center behavior rather than simple absence;
- mirror/crossover behavior is organized around this reference.

Attack next:

- define reference update law;
- distinguish physical Ground, computational reference, and coordinate origin;
- measure/reference drift in simulations and bench systems;
- derive when the reference moves and when it must remain fixed.

## C. Binary / ternary / six-route relation

Current structure:

- two opposed binary commitments;
- three movement states around the center: down/hold/up or equivalent orientation labels;
- six route addresses from 2 x 3;
- route history can matter downstream.

Attack next:

- derive six-route dynamics from a continuous model;
- define thresholds/hysteresis for route commitment;
- test whether the same route grammar survives across electrical, magnetic, mechanical, and software realizations.

## D. Oscillation and six process gates

Current structure:

`Begin -> Build -> Hold -> Build -> Break -> Loop`

These are treated as regions around a bidirectional oscillatory process rather than six unrelated serial commands.

Attack next:

- derive gate boundaries from measured trajectories;
- identify invariants that survive damping, noise, asymmetry, and scale changes;
- distinguish geometric phase, timing phase, and state-history phase.

## E. Mirror behavior

Current structure:

- mirror is a crossover/phase relation around the shared center;
- paired positions can be viewed as two orientations of one coupled relation;
- mirror traversal should preserve a receipt of orientation/sign/history.

Attack next:

- formalize mirror as an operator;
- test reversibility and information retention;
- determine which variables invert, rotate, remain invariant, or lag.

## F. Point / Path / Field recursion

Current structure:

- Point = local/intrinsic orientation;
- Path = motion/circulation of that local center along a route;
- Field = enclosing circulation/curl/boundary behavior;
- each level may contain lower-level PPF state.

Attack next:

- write explicit coordinate transforms among Point, Path, and Field descriptions;
- prevent internal spin/rotation from being confused with orbital/path or enclosing-field rotation;
- test recursive closure.

## G. Dimensional structure

Current architecture distinguishes planar, spatial, and higher recurrence descriptions instead of collapsing them.

Attack next:

- state the exact geometry and variables for each dimensional layer;
- derive projection rules between layers;
- determine which recurrence counts are structural and which are representation artifacts;
- recover conventional 2D/3D geometry where appropriate.

## H. Lattice / continuum / displacement program

Current research direction treats observed interactions as possible consequences of local structural displacement, boundary response, and nested flow/recurrence.

Attack next:

- define continuum equations;
- define lattice approximation separately;
- show convergence of lattice simulation to continuum behavior where claimed;
- identify measurable departures from standard field models.

## I. Mass-effect program

Current repository work treats mass-like response as a complete structural recurrence involving multiple coupled interactions rather than one isolated term.

Attack next:

- derive the effective inertial response from the full model;
- recover Newtonian inertial behavior in the proper limit;
- compare against relativistic constraints;
- calculate quantitative predictions before interpreting unexplained observations.

## J. Electromagnetic / magnetic program

Current structure emphasizes opposed rails, oscillation, phase, rotating magnetic fields, and mirror-related routing.

Attack next:

- map One-Wave variables onto Maxwell/LLG-compatible observables;
- identify which effects are ordinary EM/spin dynamics and which require extra One-Wave terms;
- predict a measurement that differentiates the models.

## K. Gravity / orbital / nested-wake program

Current direction explores nested displacement/capture relations across scales.

Attack next:

- build Newtonian baseline first;
- add one candidate One-Wave term at a time;
- recover Newtonian/relativistic results when the added coupling vanishes;
- test held-out orbital data, precession, lensing, timing, and cluster-scale behavior quantitatively.

## L. Cosmology / redshift / large-scale structure

Current repository contains alternative transport/redshift and nonstandard expansion ideas.

Attack next:

- identify a single explicit redshift law;
- compare against supernova, BAO, CMB, time-dilation, and surface-brightness observations;
- keep observational fit separate from mechanism preference;
- reject or revise any version that cannot match the full data set.

## M. Scale recursion

Current recurring structural idea:

- a complete local relation can become a unit at the next scale;
- the higher unit must expose an interface compatible with the relation it consumes;
- identity/history should survive compression.

Attack next:

- define the exact scale-lift operator;
- identify what is invariant and what changes with scale;
- test whether the same operator works in simulation, control, memory, and geometry without forcing false equivalence.

## N. Information / memory connection

Current science-build bridge:

- local persistent state may function as active memory;
- history, phase, route, and reference can carry information;
- reconstruction can use relational structure rather than a full stored copy.

Attack next:

- define an information measure for local state + route history;
- quantify retention, overwrite, reconstruction error, and entropy/energy cost;
- separate physical memory claims from software analogy.

## O. What would count as major progress

A science section moves forward when at least one of these happens:

- a qualitative idea becomes an explicit equation;
- an equation gets units and boundary conditions;
- a simulation reproduces a known baseline;
- a free parameter becomes measured or constrained;
- a prediction separates One-Wave from an existing model;
- an experiment measures that prediction;
- a failed prediction removes or revises a mechanism.

## Immediate science attack order

1. Freeze the minimum state vector and reference variables.
2. Formalize mirror, six-route, and six-gate operators.
3. Build the smallest continuous oscillator model that produces the route/gate behavior.
4. Derive Point/Path/Field transforms.
5. Establish standard-physics baselines for EM, mechanics/orbits, and continuum flow.
6. Add One-Wave terms one at a time with ablation tests.
7. Produce at least one quantitative differentiating prediction.
8. Use experimental failure as architecture information, not as something to hide.
