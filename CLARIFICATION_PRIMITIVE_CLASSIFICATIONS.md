## Class 3 — Oscillator / process gates

Owner: B-221, G-739, Updated 44.

```text
BEGIN -> BUILD(coherent) -> HOLD -> BUILD(unstable) -> BREAK -> LOOP
```

Count is 6. That 6 is **not** the route 6.
These are measured stability regions around a bidirectional oscillator.
HOLD here is a process region. HOLD in Class 2 is a move. Same English. Different axis.

## Quick sort when a word shows up

Ask, in order:

1. Is it a **reference** (Class 0)? Then nobody votes with it.
2. Is it a **choice or move** (Class 2)? Then it addresses a route.
3. Is it a **process region** (Class 3)? Then it is a gate on an oscillator, not a route.
4. Is it a **five** (Class 4)? Name which five.
5. Is it a **pair face** (Class 5)? Name Field or Void, view or action.
6. Is it **hardware** (Class 6) or **memory** (Class 7) or **body** (Class 8)?
7. If two answers fit, you are collapsing axes. Stop and split.
