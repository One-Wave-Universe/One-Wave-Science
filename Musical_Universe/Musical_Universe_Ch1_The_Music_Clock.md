## Gray — Standard Music Theory Reference

Twelve-tone equal temperament divides one octave into twelve equal logarithmic semitone steps:

`f_n = f_0 * 2^(n/12)`

The Music Clock is a coordinate display placed over this tuning system. It is not a new tuning system.

`+6 = -6 = ±6`

## Signed Coordinate Rule

For root `R`, tone `T`, and upward semitone distance

`k = (T - R) mod 12`

assign:

- `k = 0..5` → `+k`
- `k = 7..11` → `k - 12`
- `k = 6` → `±6`

The sign identifies route direction only.

`f(n+12) = 2f(n)`

The coordinate returns while frequency doubles.
