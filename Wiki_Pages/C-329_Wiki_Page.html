C-329: Actual State = Reference + Differential

ACTUAL_STATE = REFERENCE_STATE + DIFFERENTIAL_STATE

Trivial by construction, but guards against a specific failure: after computing a clean differential (e.g. C-328's residual), it is easy to drop the reference term entirely. An absolute state still needs the reference term added back — C-328 only showed it cancels from relative motion.
