# Algorithm and Weight Priority

```text
fixed rule
→ lookup or graph traversal
→ state machine
→ mathematical solver
→ constraint search
→ Hopfield reconstruction
→ Boltzmann exploration
```

```text
W_fixed   immutable instinct, route, permission, graph edge
W_habit   adaptive reversible activation strength
W_context temporary attention, urgency, risk, confidence
W_result  measured test or reality return
```

Learned weights never overwrite exact instinct, canonical records, hard permission, inverse routes, or checksums.
