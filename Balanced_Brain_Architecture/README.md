# Balanced Brain Architecture — Start Here

This folder is the machine-readable and implementation-facing companion to Proposed Android Brain Chapter 5 and nodes G-724 through G-731.

```text
Five-Line Dream Cube (GPU expressive slow brain)
↕
M4 Fast Subconscious Sphere
↕
One Six-Gate Administrator Double-Pyramid (CPU compressive slow brain)
```

The geometry is a functional control map. It is not a claim about anatomy or physical brain shape.

Core locks:

- Dream Engine may explore Gates 1–5 but cannot Commit.
- M4 contains instinct, habit, rapid recall, attention, timing, automatic algorithms, and virtual switches.
- Administrator controls Gate 5-to-6 oversight, override, loop break, and Commit.
- Tip-to-tip and base-to-base recursion remain inside one Administrator.
- Exact active M4 memory is mostly instinct; full exact records remain in protected external storage.
- Audio, visual, internal world, dreams, imagination, and internal dialogue remain reserved.
- Exact algorithms replace neural processing whenever possible.
