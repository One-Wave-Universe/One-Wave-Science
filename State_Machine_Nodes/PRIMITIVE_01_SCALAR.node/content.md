# Primitive 01 — Scalar

The Scalar primitive is one measurable field-state displacement relative to one defined reference.

`x = ψ - ψ₀`

Input:

- current field state `ψ`;
- reference state `ψ₀`.

Output:

- one scalar displacement `x`, carried with the reference that gives it meaning.

Zero condition:

- `ψ = ψ₀ -> x = 0`.

Displaced condition:

- `ψ != ψ₀ -> x != 0`.

Structural boundary:

- Scalar establishes one referenced value.
- It does not compare two scalar values; Differential owns that.
- It does not create direction; Vector comes later.
- It does not define Tensor or Harmonic relationships.
- Its physical material implementation remains open until bench evidence exists.

The programmable Scalar is the reference implementation of this same contract, not a replacement primitive.
