# Complete node system — bound lattice

Working system. Uses live nodes. Three drafts close the hole the solver hit.

## Chain

```text
A-101 ground
  -> A-115 compression field chi
  -> C-311 rotational view
  -> C-319 lattice organization R
  -> DRAFT-R resistance = mass / organization
  -> DRAFT-P point rotation
  -> DRAFT-B parent-child bind
  -> C-320 magnetic path weight K_L
  -> D-413 orbital bench
  -> D-416 lock output
  -> E-528 path redshift
  -> E-530 reinjection
```

No scale factor anywhere in this chain.

## Drafts that complete it

DRAFT-R. Resistance. mass / organization. Mass is not a second clock.

DRAFT-P. Point rotation. The shared organization tries to make point rotation the same for bodies on one lattice.

DRAFT-B. Parent-child bind. Parent wake scale must reach the child. A wake at 12 with bodies at 1.6 is not a bind.

## Open, not written in

kappa_R is not set. A guess that Earth's field couples lightly is a guess. It is not a node. Strength is whatever the on/off switch measures.

## Solver contract

Pass bit is point rotation, not spread. Step divides by resistance. Parent off leaves the start rate. Parent on pulls bound bodies toward one rate. Moon class falls to the face. Mercury class may hold 3:2. Magnetic channel off must still leave the face if the organization already won.

## Not in this system

Expansion. A Hubble term. Sigma from an inserted mass gap. A lunar dipole required for the lock. A guessed coupling strength.
