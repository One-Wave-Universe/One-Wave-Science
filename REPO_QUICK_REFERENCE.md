# Repo quick reference

Short full scope, then the map. If the question is not in the map, search. If the file does not say it, ask. Do not assume.

## Scope in one breath

One-Wave-Universe is three jobs, not one pile.

- Science says what is claimed and how to test it. Home: `One-Wave-Science`.
- Builds says how to make the thing. Home: `Builds`. Cell, schematics, grant face, algorithms.
- Mythos says story only. Home: `Mythos-and-Stories`. Zero scientific claims.

Beside those: `Bridge-Comand` is AI relay directions. `Bench` is private bench notes, not the grant face. `One-Wave-Universe` is the grant package and points at Builds.

Science read order starts at `AI_CANONICAL_START_HERE.md`. Gate values live on the node, not in a summary. A file in Science is a hypothesis until a test says otherwise.
