- a compressed/bound 2D lattice state;

## 1. Recursive Point–Path–Field rule

Point–Path–Field is recursive. Each outer state contains its own complete Point–Path–Field triad.

For body i define the nine-state rotational block

`R_i = { PP, PPa, PF, PaP, PaPa, PaF, FP, FPa, FF }_i`

with the following interpretation.

### Outer POINT

- `PP` — point-within-point: internal center state, deep compression, internal rotation, core state.
- `PPa` — path-within-point: circulation paths of matter/conducting fluid/current inside the body.
- `PF` — field-within-point: magnetic, pressure, displacement, and rotational field generated by the internal point state.

### Outer PATH

- `PaP` — point-within-path: instantaneous body state at the current orbital phase.
- `PaPa` — path-within-path: orbital trajectory, orbital speed, curvature, phase, and changing angular rate.
- `PaF` — field-within-path: wake/slope geometry carried, compressed, stretched, and reoriented along the orbit.

### Outer FIELD

- `FP` — point-within-field: local reference center within the surrounding field.
- `FPa` — path-within-field: circulation/transport/shear routes through the surrounding field.
- `FF` — field-within-field: the larger-scale solar/planetary field geometry and its current overlap structure.

No outer Point, Path, or Field state is allowed to collapse to one scalar if its internal P–Pa–F structure is dynamically relevant.

## 2. Compressed 2D bound-lattice state

The proposed planetary point begins from a compressed/bound lattice state rather than from a featureless point mass.

Define a local 2D bound-state descriptor

`L2_i = { D_i, C_i, T_i, gamma_i, q_i, phase_i }`

where

- `D_i` = displacement magnitude/state;
- `C_i` = compression/binding state;
- `T_i` = effective lattice tension/stiffness;
- `gamma_i` = relative-shear damping/friction parameter;
- `q_i` = structural integrity/bound-state variable;
- `phase_i` = local compression/expression/center state.

The key architectural rule is

`2D bound state -> rotational point state -> path state -> field state`

with feedback from Path and Field into the next instantaneous Point state.

This does not mean ordinary thermodynamic temperature is automatically the controlling variable. A candidate spin/shear softening channel is represented separately from literal heating.

## 3. Internal planetary POINT dynamics

The planetary POINT is not a rigid sphere with one angular velocity.

For a differentiated body define internal rotational components as available:

`Omega_inner`
`Omega_outer_core`
`Omega_conducting_fluid`
`Omega_mantle`
`Omega_crust`
`Omega_bulk`
`Omega_EM`

and relative shears

`DeltaOmega_ab = Omega_a - Omega_b`.

The internal point state is therefore

`P_i = P(L2_i, rho_i(r), Omega_layers, DeltaOmega_layers, J_i, B_i, phase_i)`

where `rho_i(r)` is the internal density profile, `J_i` is internal electrical-current structure, and `B_i` is the internally generated magnetic field where present.

### Friction / shear channel

The model must track relative motion, not an absolute generic friction constant.

Candidate dissipative/softening load:

`H_shear,i = SUM_ab gamma_ab * |DeltaOmega_ab|^2`

This quantity can modify the effective bound-state stiffness:

`T_eff,i = T_0,i * G_T(H_shear,i, C_i, q_i)`

The function `G_T` is not yet derived and must not be tuned independently per planet merely to match orbit data.

## 4. Internal EM rotation

Internal EM rotation is a first-class state variable.

For conducting planets/bodies:

`conducting-flow rotation -> current circulation J -> intrinsic B field -> EM-field rotation/orientation`

but these are coupled variables rather than identical quantities.

Track at minimum:

- internal conducting-flow angular state;
- electrical-current circulation state;
- intrinsic magnetic-field strength and multipole geometry;
- magnetic-axis orientation;
- EM-field rotation/orientation relative to matter rotation;
- Sun/neighbor field orientation where relevant.

Relative matter/EM rotation:

`DeltaOmega_matter_EM = Omega_matter - Omega_EM`.

The candidate role of EM is to modify the integrity/stiffness/response of the displacement shell, not to act as a generic extra gravity-like acceleration.

## 5. Point-spin coupling to the bound state

Whole-body and internal point rotation are not appended after the displacement calculation. They are part of the displacement state itself.

Define a characteristic rotational measure using both angular rate and physical scale:

`Vrot_i = Omega_bulk,i * R_i`

and retain internal layer measures separately.

A generic candidate bound-state relation is

`T_eff,i = T_0,i * G( C_i, D_i, Vrot_i, DeltaOmega_layers, EM_i )`.

This permits, but does not assume, a spin/shear-softening effect in which increased relative circulation changes local lattice stiffness or locking.

The crucial rule is interaction, not independent additive corrections:

`size x spin x internal circulation x EM x compression -> point state`.

## 6. PATH dynamics

The outer PATH contains its own P–Pa–F structure.

Orbital angular rate:

`Omega_path,i(t) = |r_i x v_i| / |r_i|^2`

for a Sun-centered diagnostic representation, while the dynamical solver itself may use relational edge variables.

The Path state includes:

- instantaneous orbital phase;
- orbital speed;
- radial/tangential decomposition;
- curvature;
- changing angular rate;
- point state carried along the path;
- field deformation associated with that motion.

Path response is not independent of point spin. Coupling terms such as

`C_PPa`, `C_PF`, `C_PaF`

must be available to represent interaction between spin/internal circulation, orbital motion, and carried field geometry.

## 7. FIELD dynamics

The outer FIELD is the currently overlapping solar/planetary environment.

For each body j define a moving body-specific active domain

`Omega_j(t)`

and slope profile

`S_j(r,t) = |grad Phi_j(r,t)|`.

The field seen by body i is constructed only from active overlapping domains at the current time:

`S_local,i(t) = SUM_j W_ij(t) S_j(r_i,t)`

where `W_ij` is a boundary/overlap weight derived from the finite-range law and must not be a hand-set universal cutoff.

The relational driver remains

`DeltaS_i(t) = S_local,i(t) - S_ref,i(t)`.

No wake memory or relay memory is used.

## 8. Finite range is an emergent interaction result

A planet does not receive an externally assigned gravity radius.

Its active range is a state output:

`R_active,i(t) = R[ L2_i, D_i, R_i, rho_i(r), recursive PPaF state, EM_i, DeltaS_surroundings ]`.

Thus two bodies with equal mass can have different active displacement structures if their size, density, internal rotation, EM state, compression, or surrounding reference differs.

Likewise the same planet can have a changing active domain over its orbit.
