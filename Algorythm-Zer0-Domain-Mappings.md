# Algorythm-Zer0 — Domain Mappings

**Authority:** `Algorythm-Zer0.md` defines the primitive grammar. This file defines ways that grammar can be used without changing the primitives.

The strongest current cross-domain interpretation is **connection**: two sides maintain a referenced relationship, make choices inside that relationship, retain what happens, and recursively update the connection.

This is a mapping principle, not a claim that every physical or biological pair literally implements the same mechanism.

---

# 1. GENERIC CONNECTION MAPPING

Primitive:

```text
SIDE A
  ↕
SHARED REFERENCE / RELATION
  ↕
SIDE B
```

Algorythm-Zer0 form:

```text
FIELD ↔ GROUND/REFERENCE ↔ VOID
→ EXPRESS/COMPRESS CHOICE
→ PAIRED TERNARY
→ 4 VIEWS / 4 ACTIONS
→ 5-STATE RETENTION
→ 6-STEP RECURSION
↺
```

The important property is that neither side is modeled in isolation. The state belongs to the **relationship plus both participants**.

A higher level preserves the lower relationship instead of replacing it.

---

# 2. TWO SIDES OF A BRAIN — ARCHITECTURAL MAPPING

**Status:** conceptual/neural architecture mapping; not a claim that biological hemispheres literally execute this exact six-level algorithm.

```text
SIDE A = one neural/hemisphere process
REFERENCE = shared body/world/current task state
SIDE B = paired neural/hemisphere process
```

The useful idea is connection across a shared reference:

```text
SIDE A produces/expresses a relation
↕
shared reference keeps both sides about the same current state
↕
SIDE B checks/conditions/returns a relation
```

The pair can disagree, defer, synchronize, or resolve without erasing either side.

---

# 3. BRAIN ↔ BODY STATE — ARCHITECTURAL MAPPING

```text
FIELD SIDE = newly interpreted/sensed/desired brain relation
REFERENCE = current whole-body state
VOID SIDE = body constraint, feedback, current/last action state
```

The connection is recursive:

```text
brain view
→ referenced against body state
→ action
→ body changes
→ changed body state becomes new input/reference
↺
```

This mapping is intended for control architecture. It should not be presented as established neuroscience without biological evidence.

---

# 4. TWO FRIENDS / TWO PEERS

```text
SIDE A = person A's current view
REFERENCE = shared situation / agreed context
SIDE B = person B's current view
```

The shared state is not simply A or B. It includes the connection between them.

A useful mapping is:

```text
EXPRESS / COMPRESS
= open/widen possibility ↔ narrow/commit possibility

MODULATE / HOLD / RESET
= revise relation ↔ preserve relation ↔ re-establish common ground

CONFIRM / DEFER / DENY
= agree/permit ↔ withhold judgment ↔ reject/block
```

The retained history of the interaction changes the next interaction; in that sense the relationship itself carries memory.

---

# 5. HUMAN ↔ AI PARTNERSHIP

```text
HUMAN
  ↕
SHARED TASK / AUTHORITATIVE STATE
  ↕
AI
```

Neither side should silently replace the shared reference with its own assumptions.

A practical mapping:

```text
FIELD = new proposal, interpretation, or possibility
REFERENCE = explicit shared goal + current verified project state
VOID = checking, constraints, prior commitments, action authorization
```

The algorithm then becomes a collaboration loop:

```text
shared state
→ expose a choice
→ propose/change/hold/reset
→ confirm/defer/deny
→ inspect through multiple views
→ choose/condition action
→ retain the result
→ recur from the changed shared state
```

This makes the relationship itself part of the state. The next cycle should inherit what both sides already established instead of rebuilding context or guessing.

For repo work, the repository is part of the authoritative shared reference.

# 6. CONNECTION RULE ACROSS DOMAINS

The recurring pattern is:

```text
TWO SIDES
+ ONE SHARED REFERENCE
+ CHOICE
+ MIRRORED RESPONSE
+ RETAINED HISTORY
+ RECURSION
= A CONTINUING CONNECTION
```

Possible mappings include:

```text
hemisphere ↔ hemisphere
brain ↔ body
sensor ↔ actuator
cell ↔ cell
agent ↔ agent
friend ↔ friend
human ↔ AI
world ↔ model
Field world ↔ mirrored loop-space
```

These are examples of the same **connection grammar**. They are not evidence that all examples share identical physical implementation.

---

# 7. DOMAIN-MAPPING RULE

Every new mapping must answer:

```text
Who/what are the two sides?
What is their shared reference?
What information is actually shared?
What is the binary Choice?
What are the paired ternaries?
What do the four views/actions expose?
What is retained across five states?
What does one six-step loop accomplish?
How does the resolved connection become the starting state of the next loop?
What test would show this mapping fails?
```

If those questions cannot be answered, the mapping is not ready to be treated as an Algorythm-Zer0 implementation.
