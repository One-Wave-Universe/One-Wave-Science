# Challenge 06 — Planetary Point Rotation, Magnetic Reorganization, and Bound/Unbound Lattice

**Target:** L2 coupled-state derivation -> L3 recovery of known planetary rotation/magnetic facts -> L4 discriminating prediction.

## Working One-Wave hypothesis

Planetary rotation is not treated as one isolated spin variable.

The candidate state is:

```text
bound lattice state
    + point rotation
    + internal differential rotation
    + magnetic-field geometry
    + parent-field / tidal relation
    + local bound <-> unbound lattice transition
    -> reorganized effective lattice state
    -> observed rotational / magnetic response
```

The key proposal is that rotation, magnetism, and gravitational/tidal state are coupled through the same underlying lattice response rather than being independent corrections.

## Tidal-locking test

A tidally locked body is a high-value control because orbital/path rotation and local point rotation are constrained into a stable relation.

The hypothesis to test is:

```text
parent gravitational/tidal reference
      +
child point rotation
      +
child magnetic state
      ->
stable coupled lattice orientation
```

Do not assume magnetic locking merely because tidal locking is present.

The model must predict when a magnetically active locked body should retain, weaken, reorient, or lose an intrinsic field.

## Planetary contrast set

### Venus

Required facts to reproduce:
- very slow rotation;
- retrograde spin;
- no present internally generated global magnetic field;
- induced magnetic environment from solar-wind interaction.

The model must explain whether Venus corresponds to a different bound/unbound lattice regime, a different internal differential-rotation state, or both.

### Uranus

Required facts to reproduce:
- extreme axial tilt / sideways point rotation;
- retrograde sense relative to most planets;
- intrinsic magnetic field strongly tilted relative to the rotation axis;
- magnetic field significantly offset from the planetary center.

The model must not simply say "impact caused tilt" and stop. If One-Wave claims lattice reorganization, it must calculate what persistent internal/magnetic state follows from the changed point rotation.

### Neptune

Required facts to reproduce:
- more conventional bulk axial orientation than Uranus;
- strongly tilted and offset intrinsic magnetic field;
- rapid point rotation.

This is a crucial control: if Uranus and Neptune both show unusual magnetic geometry despite very different bulk axial orientation, the model must separate magnetic/lattice reorganization from simple axial tilt.

## Common-state requirement

One parameter set or one scaling law must cover Venus, Uranus, and Neptune.

Disallowed:
- tuning a separate magnetic coefficient for each planet;
- defining a separate lattice rule after looking at each anomaly;
- using "bound" and "unbound" only as descriptive labels.

Required:
- one state equation;
- planet inputs from independently measured mass, radius, density structure, rotation, orbital/tidal state, and magnetic measurements;
- outputs compared against observed rotation/magnetic geometry.

## Link to gravity relay / parent reference

The planetary state sits inside a parent field.

[
X_{m child}
=
U(
X_{m child},
X_{m parent},
X_{m siblings}
)
]

The child contributes back to the parent field while inheriting the parent's resolved reference.

The local gravitational influence is therefore tested as finite-range/relayed rather than assumed to propagate unchanged to infinity.

For planetary work, the Sun is the immediate parent reference; moons provide child/subchild tests.

## Strong discriminators

A useful One-Wave result should predict at least one of the following before fitting:

1. a relationship between magnetic-axis offset/tilt and internal differential rotation;
2. a threshold separating stable intrinsic-field states from induced-only states;
3. a tidal-locking regime that predicts magnetic-field persistence or reorganization;
4. a rotation/magnetic observable for Uranus or Neptune that differs from standard interior-dynamo expectations;
5. a moon/planet pair where the relay/lattice model predicts a measurable coupling not captured by ordinary tidal + dynamo modelling.

## Failure condition

If the model requires independent rules for Venus, Uranus, and Neptune, or if every output is obtained only by fitting planet-specific parameters, the proposed common lattice law fails.

If the final equations reduce exactly to standard tidal dynamics plus standard dynamo physics with no new invariant or prediction, classify the result as L3 recovery rather than new physics.
