# One-Wave Science Documentation Map

Repository entry points remain at the repository root. Supporting documentation is grouped here by job.

- architecture/ — architecture families, clarifications, presentation structure, and system plans.
- audits/ — repository/science audits and dependency reviews.
- updates/ — chronological UPDATED handoff and model-development documents.
- maps/ — science and mathematics attack maps.
- reference/ — compact reference authorities, terminology, Rabbit-Hop references, and math notes.
- verification/ — explicit verification matrices for unverified hypothesis layers.
- open-work/ — bounded unresolved research/work packets.
- governance/ — human/art governance documents.

Machine-critical registries and canonical entry files intentionally remain at repository root.
