# Hardware and Circuits

## Purpose
Physical implementation notes for breadboards, balanced rails, motors, magnetic memory, sensors, actuators, and component choices.

## Belongs here
- Balanced / mirrored rail circuits
- Virtual ground and reference architecture as physical hardware
- MOSFET, coil, ferrite, pot, LED, and sensor work
- Three-winding ternary motor and actuator concepts
- Magnetic memory / hold concepts
- Reinjection loops and power-path experiments
- Bench wiring, measurement, parts, and build constraints

Keep simulation-specific implementation in document 05 and validation results in document 11.
