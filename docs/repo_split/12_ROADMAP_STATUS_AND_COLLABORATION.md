# Roadmap, Status, and Collaboration

## Purpose
Keep project-wide state, priorities, open work, branch/PR status, collaborator outreach, and handoff information in one place.

## Belongs here
- Current build status by subsystem
- What is done, active, blocked, or proposed
- PR / branch / release tracking
- Smallest next test or next implementation step
- Cross-project dependencies
- Collaborator needs and outreach status
- Handoff notes for humans and AI workers

## Rule
Do not duplicate subsystem documentation here. Link to the owning document and record only status, dependency, owner, and next action.
