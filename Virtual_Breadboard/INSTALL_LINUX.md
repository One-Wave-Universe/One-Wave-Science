# Install Virtual Breadboard on Linux

No terminal needed. Download the installer, click Install, open it from your app menu.

## 1. Download

Open the release page:

**https://github.com/One-Wave-Universe/One-Wave-Science/releases/tag/vbb-linux-1.0.0**

Under **Assets**, click:

- **VirtualBreadboardSimulator-linux-amd64.deb** — recommended for Ubuntu, Debian, Linux Mint, Pop!_OS, Zorin, Elementary
- **VirtualBreadboardSimulator-linux-x64.AppImage** — for Fedora, Arch, openSUSE, or if the .deb does not install

Your browser saves the file to your Downloads folder. You do not need a terminal to download it.

## 2. Install the .deb (Ubuntu / Debian / Mint / Pop!_OS)

1. Open your **Downloads** folder.
2. Double-click **VirtualBreadboardSimulator-linux-amd64.deb**.
3. Your Software Install / App Center / GDebi window opens.
4. Click **Install** (enter your password if asked).
5. When it finishes, open your app menu and search for **Virtual Breadboard Simulator**.
6. Click it to start building circuits.

Tip: right-click the app in the menu and choose **Add to Favorites** or **Add to Desktop** if you want a shortcut.

## 3. Or use the AppImage (other Linux distros)

1. Open **Downloads**.
2. Right-click **VirtualBreadboardSimulator-linux-x64.AppImage** → **Properties**.
3. Allow running as a program / make executable (wording varies by desktop).
4. Double-click the AppImage to launch.

If double-click does nothing, your system may need FUSE support for AppImages — in that case use the .deb on Ubuntu/Debian-family instead.

## 4. You are done

The app should open a virtual breadboard. Place parts, add wires, and run circuits for student practice or cell tests.

## Updating later

Come back to the same Releases page, download the newer .deb or AppImage, and install over the old one the same way (double-click → Install).
