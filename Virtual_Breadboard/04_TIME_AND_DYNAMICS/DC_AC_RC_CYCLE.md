# DC / AC / RC cycle

Not a linear conveyor. Bidirectional at center.

```
DC   opposed bias     → + | 0 | − ←
AC   counter-motion   through G both ways
RC   delay, damping, window, anti-chatter
```

Hold = pair recloses at G inside the window (oscillator still live).
Movement = lean persists through the window.
Quit = two stations both loud opposite.

Full flip: new views up and last action down as one crossing.
