# Stage 1 Real Millivolt Ternary — Physical Build Sheet

This is the literal bench-build translation of the **Stage 1: Real
Millivolt Ternary** preset (`presetStage1TernaryParts()` in `js/app.js`,
button under **Ternary cell (G-744)** in the sidebar). Every hole below is
the exact one the simulator itself uses — this file is generated by hand
from that same function, not a separate guess at the circuit.

Board: one full-size 830-point breadboard (63 columns), rows `a-e` top
strip, `f-j` bottom strip, center channel between `e` and `f`. All column
numbers below refer to that board.

**Read "Parts not in your bin" (bottom) before you buy anything or start
building — three of the parts below don't exist as simple through-hole
components.**

## Parts not in your bin (read this first)

1. **TLV3202 is surface-mount only** (SOIC-8 or VSSOP-8) — there is no
   through-hole DIP-8 TLV3202. To breadboard it you need a SOIC-8-to-DIP
   (or VSSOP-to-DIP) breakout/adapter board with the chip soldered onto
   it. The simulator's part is drawn as a DIP-8 body purely because that's
   the real, physical footprint a breakout board like this gives it once
   soldered down — the pinout table below matches the *chip's* real pin
   order either way.
2. **AO3400A (N) and AO3401A (P) are SOT-23 only** — same story, each
   needs its own SOT-23-to-DIP breakout board. This is exactly what the
   build spec calls "AO3400A MOSFET breakouts": budget two small adapter
   boards, not two bare loose transistors.
3. **The ±40mV "lean" signal has no battery you can buy.** The simulator
   models it as two idealized 0.04V batteries purely so a click of a
   switch can demonstrate all three states. On a real bench, generate
   `SIGNAL` instead with one of:
   - A precision function generator or bench PSU's fine-adjust output,
     set to `V0 ± 0.040V` (measure `V0` first, then add/subtract).
   - A second 124kΩ/1kΩ-class precision divider off the 5V rail (the
     same technique R1-R4 already use), sized for a ±40mV offset instead
     of ±20mV, switched in exactly where the batteries sit in the
     simulator.
   - A DAC or precision multi-turn pot referenced to `V0`, if you want a
     continuously variable test input instead of three fixed states.
   Whichever you choose, it plugs in at the same two nodes the simulator's
   `swPlus`/`swMinus` switches use (see the hole table) — the rest of the
   circuit is unaffected.
4. **TLE2426 pinout**: this one genuinely is a real TO-92 through-hole
   part and should drop straight onto the board, but double-check its
   3-pin assignment (`IN`/`GND`/`OUT`) against the specific datasheet
   revision you're holding before wiring it — don't take the mapping
   below as gospel over the part in your hand.

## IC pin orientation

**TLE2426** (TO-92, flat face toward you, pins down, left-to-right):
`IN` → `GND` (common) → `OUT`. `IN` ties to the 5V rail, `GND` to the
supply return, `OUT` is `V0` (nominally 2.500V from a 5V rail).

**TLV3202** (real chip pin order, 8 pins — matches both the SOIC-8 chip
and the simulator's DIP-8 breakout footprint exactly):

| Pin | Name | This build's node |
|---|---|---|
| 1 | OUT1 | `OUT1` (active-LOW for "Right" — see note below) |
| 2 | IN1− | `SIGNAL` |
| 3 | IN1+ | `X` (`V0 + 20mV` reference) |
| 4 | GND | `GND` |
| 5 | IN2+ | `Y` (`V0 − 20mV` reference) |
| 6 | IN2− | `SIGNAL` |
| 7 | OUT2 | `OUT2` (active-HIGH for "Left") |
| 8 | VCC | `P` (+5V) |

Note pins 2/3 are deliberately **not** in the "obvious" `IN+ = SIGNAL`
order — see the README's "Ternary cell (G-744)" section for why: `Q1` is
a real P-MOSFET and needs an active-LOW drive, so channel 1's inputs are
swapped to produce that directly, with no inverter.

**AO3400A / AO3401A** (SOT-23, on their breakout boards — check your
specific breakout's own silkscreen, since adapter pinouts vary):
`gate`, `drain`, `source`, matching the datasheet pin order for the bare
SOT-23 die underneath.

## Jumper / bridge wires

The nodes above span more columns than any one column's 5-hole strip can
reach, so these plain jumpers carry a node across the gap between them —
exactly as the simulator itself wires them:

| From | To | Carries |
|---|---|---|
| b5 | g20 | P → TLV3202's VCC-pin column |
| j5 | a23 | GND → TLV3202's GND-pin column |
| e8 | a11 | V0 → the lean/hold section's V0 column |
| a21 | g22 | SIGNAL (top half) → SIGNAL (TLV3202's IN2− column) |

## Test points and expected voltages

Probe these with a multimeter (or the simulator's Scope Probe, already
placed at the same 4 points) referenced to `GND` unless noted:

| Test point | Hole | Hold (swHold closed) | Right (swPlus closed) | Left (swMinus closed) |
|---|---|---|---|---|
| `V0` | c8 | ~2.500V | ~2.500V | ~2.500V |
| `X` (window-hi ref) | a22/e22 | ~2.520V | ~2.520V | ~2.520V |
| `Y` (window-lo ref) | g23/f23 | ~2.480V | ~2.480V | ~2.480V |
| `SIGNAL` | e21/e20 area (or the scope at h22) | ~2.500V | ~2.540V | ~2.460V |
| `OUT1` (pin1, active-low) | e20 (scope at b20) | ~5.0V (HIGH) | ~0V (LOW) | ~5.0V (HIGH) |
| `OUT2` (pin7) | f21 (scope at h21) | ~0V (LOW) | ~0V (LOW) | ~5.0V (HIGH) |
| `MEM` (the ternary output) | a28/b28 (scope at e28) | **~2.500V** | **~5.0V** | **~0V** |

If `MEM` in the Right case reads meaningfully below ~4.9V, check `Q1`'s
orientation first — a P-MOSFET wired backwards (source/drain swapped)
reproduces exactly the self-limiting behavior described above, stalling
partway up instead of reaching the rail.

## Honesty limits carried over from the simulator

- `V0`'s real TLE2426 has its own load-regulation and noise-rejection
  limits beyond what the simulator's idealized rail-splitter models —
  don't expect the physical part to hold `V0` as perfectly flat under a
  fast-changing load as the simulator does.
- The comparator's real ~2mV input offset voltage and finite propagation
  delay (tens of ns) are not shown in the table above; they're small
  enough at this ±20mV window to ignore for a first bring-up, but expect
  the exact switching point to be a few mV off from the 20.00mV/2.500V
  numbers above, part to part.
- This sheet only covers **Stage 1** — the single-cell window-comparator
  ternary decision. It does not yet include group memory or toward/away
  neighbor coupling (see Cal H for that mechanism in isolation); wiring
  those onto a physical Stage 1 cell is future work, not covered here.
