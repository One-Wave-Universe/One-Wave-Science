It was drafted with a standalone `Node_01…Node_26` naming scheme that does **not** match this repository's canonical node IDs. No new node IDs are created here — this file only proposes a chapter grouping over existing nodes. This is not `Book1_Micro` material (that book covers particle-scale physics); it belongs with the route-grammar/motor-memory line already staged in `Nodes/G-71x`–`G-72x` and referenced from `Books/Proposed_Android_Brain/`.

### Chapter 1 — The Single Continuous Carrier Wave

Grounding nodes: `A-112` Persistent Mode, `A-112a` Traveling Lattice Rupture, `A-114` Dispersion Relation, `A-113` Projection.

- **1.1 Paradigm shift** — reinterpreting subatomic "particles" as localized field excitations or measurement events rather than discrete objects. Covered by `Book1_Micro` Ch01 (`What Is A Particle`) and `A-112` Persistent Mode.
- **1.2 Topological continuity** — how a single unbroken wave propagates without splitting into disconnected packets. `A-112a` Traveling Lattice Rupture already models conservative relocation of a localized defect (equal opening ahead / reclosure behind) without automatic permanent scarring — the existing mechanism for this claim.
- **1.3 Energy conservation across scale** — maintaining amplitude across phase inversions without structural tearing. `A-114` Dispersion Relation (exact lattice characteristic equation) plus `E-509` Propagation Limit.

### Chapter 2 — The N×2±1 Dynamic Engine

Grounding nodes: `G-721a` Fibonacci Word Hop Validation, `G-721b` Sturmian Binary Branch Grammar, `B-224` Two Choices (Compression/Expression).

- **2.1 Harmonic binary split** — the 2N carrier flanked by ±1 expansion/contraction bounds. Maps to `B-224` Two Choices, which formalizes the compression/expression pair already used unnamed inside `B-221` Loop.
- **2.2 Odd-integer guarantee** — 2N±1 preventing odd/even deadlock in modulo-12/26 spaces. This is the combinatorial territory `G-721a` (Fibonacci word) and `G-721b` (Sturmian binary branch grammar) already occupy; no existing node yet states the odd-integer deadlock argument explicitly — flag as a gap to fill under `G-721b`, not a new node.
- **2.3 Transition shift** — linking state N to N+1 via a phase-inverted lookahead. Candidate home: `G-721c` Episturmian Multi-Route Directive Grammar (lookahead over multiple candidate routes).

### Chapter 3 — Balanced Ternary Routing & Node Mesh

Grounding nodes: `B-224` Two Choices, `D-408` Sixfold 2D Triangular-Hexagonal Lattice, `D-409` Twelvefold 3D Close-Packed Coordination, `G-721` Mirrored Alphabet Rabbit-Hop Coordinate Algorithm.

- **3.1 Choice logic [−1, 0, +1]** — Negative (Contraction) / Hold (Zero Pivot) / Positive (Expansion). This is `B-224` Two Choices plus the Mirror Gate zero reference (`C-301`, Ch4) supplying the Hold state.
- **3.2 The 1D alternating 6/12 chain** — spatial neighbor update with n−1 coupling. `D-408` Sixfold 2D Lattice and `D-409` Twelvefold 3D Close-Packed Coordination are the existing 6-fold/12-fold coordination nodes; `D-411` Mirrored Axis Pairs and Directed Route Counts already covers directed adjacency.
- **3.3 Modulo-12/modulo-26 alignment** — bridging the 12-chromatic tonal space with the 26-letter alphabet through a Node 13 pivot. This is exactly what `G-721` Mirrored Alphabet Rabbit-Hop Coordinate Algorithm does (it is literally the 26-letter/route-coordinate grammar); the 12-tone side is covered by `Musical_Universe/` (`E-510`–`E-514`).

### Chapter 4 — The Mirror Gate & Boundary Integration

Grounding nodes: `C-301` Mirror Gate, `C-317` Boundary-Tension Weave, `B-207` Threshold State, `B-209` Break Condition.

- **4.1 Zero-point crossing** — symmetrical phase reflection across inverted quadrants. This is `C-301` Mirror Gate directly (gate: GREEN for function, YELLOW for origin question CCD-03).
- **4.2 Field closure mechanics** — how the Mirror Gate resolves boundary conflicts between micro-node interactions and macro-scale propagation. `B-207` Threshold State → `B-209` Break Condition → `B-210` Return is the existing threshold/closure chain; `C-317` Boundary-Tension Weave covers confinement-style boundary structure.
- **4.3 Spatial vector folding** — translating 2D planar switch dynamics into 3D rotational depth vectors. Candidate home: `D-409` Twelvefold 3D Close-Packed Coordination (already the 2D→3D lattice step) plus `A-117` Dimensional Integrity and Projection Declaration, which explicitly governs 2D/3D/4D projection metadata.

### Chapter 5 — Neuromuscular Motor Recall & Phonetic Triggers

Grounding nodes: `G-722` Android Subconscious Motor Memory Architecture, `G-723` Pisot-Salem-Mahler Motor Stability Audit, `G-704` Kabeuchi, `G-721` Mirrored Alphabet Rabbit-Hop Coordinate Algorithm.

- **5.1 Cerebellar phase priming** — routing phonetic acoustic transients directly into motor pathways to bypass cognitive delay. `G-722` Android Subconscious Motor Memory Architecture (lifecycle: PROPOSED_BUILD) is the existing hybrid procedural-memory/subconscious-movement architecture this belongs under.
- **5.2 The 26-point activation matrix** — mapping phonetic classes to matrix nodes for gesture execution. `G-721` already supplies the 26-letter coordinate grammar; this section would be a G-721 application note, not a new node.
- **5.3 De-tension loops** — an explicit zero-voltage reset node to prevent fatigue during continuous cycles. `G-704` Kabeuchi (route grammar / evaluation-control classification) and `G-706` Validation are the existing candidates for a reset/de-tension role; `G-723` Pisot-Salem-Mahler Motor Stability Audit is the existing spectral check that would confirm a reset point isn't itself destabilizing.
