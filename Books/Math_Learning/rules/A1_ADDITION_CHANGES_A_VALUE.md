# A1 — Addition Changes a Value

## The rule

> **Adding a number means changing the starting value by that amount in the positive direction.**

`3 + 2 = 5`

Start with `3`.

`+2` tells you to move the value up by two.

So the value changes:

`3 → 4 → 5`

The `3` is where you started.

The `+2` is the change you made.

The `5` is where you ended.

---

## What to look for

Use this rule when you see one amount being increased by another amount.

Examples:

- `4 + 3`
- `10 + 6`
- `x + 5`
- `a + b`

The numbers or symbols can change. The logic does not.

There is a starting value and a positive change being added to it.

---

## What the plus sign means

The `+` sign is an instruction to combine a positive change with the value already there.

`7 + 4`

means:

> Start at 7 and change it by +4.

It does not mean that `7`, `+`, and `4` are three unrelated symbols that must be memorized as a pattern.

They describe a change.

---

## Numbers are not required

The same rule still works when the amount is unknown.

`x + 4`

means:

> Whatever value `x` currently has, increase it by 4.

If `x = 3`, then:

`x + 4 = 7`

If `x = 10`, then:

`x + 4 = 14`

The rule did not change when the value of `x` changed.

---

## Direction matters

Addition with a positive number moves the value upward from where it started.

`5 + 3 = 8`

Addition with a negative number moves in the opposite direction:

`5 + (-3) = 2`

That later connects directly to subtraction and opposites.

---

## Worked example

Suppose you already have 6 guitar picks and someone gives you 3 more.

Starting amount:

`6`

Change:

`+3`

New amount:

`9`

So:

`6 + 3 = 9`

The math is just recording what changed.

---

## What this rule will connect to later

This rule is the first half of the movement/cancellation family.

Later rules build directly on it:

- subtraction reverses an added change;
- positive and negative changes can cancel;
- adding zero creates no change;
- equations can be solved by undoing an added change;
- coordinates and rates can describe repeated changes.

Do not discard this rule after basic arithmetic. It stays underneath later algebra.

---

## Build / lock lesson rule

When this rule is turned into a lesson:

### Build it — 3 problems

Use three real problems that make the same addition logic visible while changing only a little at a time.

The learner should be able to see the pattern forming.

### Lock it down — 3 problems

Use three new problems where the same rule is still required but the presentation changes enough that the learner has to recognize the rule rather than copy the previous problem.

Do not show the answer on live problems.

Each live problem must link back to this rule with a **Uses: A1 — Addition Changes a Value** reference.

If the learner is stuck, identify the first piece of this rule that is not making sense instead of dumping the solution.

---

## Short version

> **Start with a value. Add a positive change. The value moves up by that amount.**
