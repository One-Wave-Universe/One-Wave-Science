# Canon and Core Model

## Purpose
The shortest authoritative description of the One-Wave model: primitives, definitions, lifecycle, core relationships, canonical terminology, and what is adopted versus proposed.

## Belongs here
- One-wave primitive and reference/void framing
- Core six-gate / mirrored architecture
- Lifecycle and canonical state sequences
- Adopted terminology and invariants
- Clear separation of canon, proposal, metaphor, and experiment
- Cross-links to detailed physics, hardware, brain, and lattice documents

## Does not belong here
Long derivations, implementation logs, app instructions, or repeated copies of subsystem details.
