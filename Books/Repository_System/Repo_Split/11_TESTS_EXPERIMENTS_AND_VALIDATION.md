# Tests, Experiments, and Validation

## Purpose
One place for evidence: controls, experimental runs, falsification criteria, simulator qualification, hardware measurements, and parity checks.

## Belongs here
- Physics experimental-wing test map
- Control versus hypothesis-experiment classification
- Virtual Breadboard qualification stages
- ngspice cross-checks
- Hardware bench tests and measured results
- Reproducible run order
- Expected result, observed result, and interpretation
- Failures, uncertainty, and unresolved discrepancies

## Rule
Do not turn hypotheses into conclusions here. Record what a test can actually establish and link back to the theory or subsystem it evaluates.
