# Book 2 — Chapter 3: Electric and Magnetic Mirror

One-Wave proposes a correspondence between two kinds of organization of the same underlying state:

```
electric candidate  -> gradient / radial response
magnetic candidate  -> curl / rotational response
```

A compact exploratory notation is

```
E ~ grad(P_c)
B ~ curl(P_c)
```

This motivates the phrase **electricity and magnetism are mirrored**, but the phrase is ahead of the proof.

A literal 90-degree rotation, a phase relation, an electromagnetic duality, and a geometric reflection are not automatically the same mathematical operation. The model must determine which transformation—if any—actually maps the two observables while respecting dimensions, conservation, and the Maxwell limit.

Until then, “magnetism is electricity mirrored” is a **derivation target**, not a completed result.

If the derivation succeeds, CELL magnetic switching can be reconsidered as a physical reorientation process. If it fails, the architecture keeps the experimentally valid magnetic behavior without the deeper identification.

Canonical science node: **G-767**.
